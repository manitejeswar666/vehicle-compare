# Vehicle Comparison Tool

Compare two vehicles side by side with spec cards and charts.

**Live:** https://vehicle-compare-two.vercel.app/

## Built with
- React + Vite
- Recharts for the bar charts
- Plain CSS

## Features
- Pick any two vehicles from a list of 10
- Side-by-side spec cards
- Four comparison charts (price, mileage, power, engine)
- Responsive layout
